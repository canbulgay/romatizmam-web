# Romi Web (Landing + Privacy) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the bilingual (TR default, EN) Romi marketing site with a hero landing page and a privacy policy page, matching the `Romi Minimal.dc.html` design.

**Architecture:** A statically generated Next.js App Router site with one `[locale]` segment. `next-intl` owns routing (`tr` unprefixed, `en` under `/en`), browser-language detection in `src/proxy.ts`, and message loading from `messages/*.json`. All components are server components except the language switcher.

**Tech Stack:** Next.js 16.3 (App Router, TypeScript), React 19, pnpm 10, Tailwind CSS 4.3, next-intl 4.14, Playwright 1.63.

**Spec:** `docs/superpowers/specs/2026-10-03-romi-web-design.md`

## Global Constraints

- Node >= 20.9 (22.x is installed). Package manager is pnpm; never use npm or yarn.
- Locales are exactly `tr` and `en`; `tr` is the default and has no URL prefix.
- URLs: `/`, `/privacy`, `/en`, `/en/privacy`. `/tr` and `/tr/...` redirect to the unprefixed URL.
- Next.js 16 names the middleware file `src/proxy.ts`. Do not create `middleware.ts`.
- In Next.js 16 `params` is a `Promise`; always `await params`.
- Copy is verbatim from this plan's JSON. Do not reword, re-punctuate or "fix" Turkish text. Keep the typographic apostrophe `’` where it appears.
- Sizes, colours, radii, shadows and rotations are the values written in this plan; they were copied from the design file. Do not round or substitute them.
- The mobile breakpoint is 900px, exposed as the Tailwind variant `desk:` (min-width 900px).
- `LocaleSwitcher` is the only `'use client'` file.
- Placeholders stay as written: `appStoreUrl` = `https://apps.apple.com/`, `siteUrl` = `https://example.com`.
- Out of scope: features/FAQ/other landing sections, single-phone hero, analytics, contact form, deployment.
- End every commit message with the trailer `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- Playwright tests run against the production build; the config builds and starts the server itself.

## Review Focus

1. `Accept-Language` with regions and weights (`en-GB,en;q=0.9,tr;q=0.8`): expect English. Tested in Task 2.
2. A browser that prefers neither language (`de-DE`): expect Turkish at `/` with no redirect. Tested in Task 2.
3. A visitor who chose English, returning to `/` on a Turkish browser: expect the stored choice to win and land on `/en`. Tested in Task 4.
4. Unknown paths in either locale (`/nope`, `/en/nope`): expect HTTP 404 with the heading in that locale, not a blank or English-only page. Tested in Task 6.
5. Long unbreakable strings (the e-mail address, long Turkish words) on a 320px screen: expect no horizontal scroll on the privacy page. Tested in Task 5.

import { readFileSync } from 'node:fs';
import { join } from 'node:path';
import { expect, test } from '@playwright/test';

function keyPaths(value: unknown, prefix = ''): string[] {
  if (Array.isArray(value)) return value.flatMap((v, i) => keyPaths(v, `${prefix}[${i}]`));
  if (value && typeof value === 'object') {
    return Object.entries(value).flatMap(([k, v]) => keyPaths(v, prefix ? `${prefix}.${k}` : k));
  }
  return [prefix];
}

const load = (locale: string) =>
  JSON.parse(readFileSync(join(process.cwd(), 'messages', `${locale}.json`), 'utf8'));

test('tr and en messages have identical keys', () => {
  expect(keyPaths(load('tr')).sort()).toEqual(keyPaths(load('en')).sort());
});

test('both locales have 11 privacy sections', () => {
  expect(load('tr').privacy.sections).toHaveLength(11);
  expect(load('en').privacy.sections).toHaveLength(11);
});

import { hasLocale } from 'next-intl';
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested) ? requested : routing.defaultLocale;
  return {
    locale,
    messages: (await import(`../../messages/${locale}.json`)).default,
  };
});

- [ ] **Step 3: Write `src/i18n/alternates.ts`**

```ts
import { routing, type Locale } from './routing';

type Path = '' | '/privacy';

export function localizedPath(locale: Locale, path: Path): string {
  if (locale === routing.defaultLocale) return path || '/';
  return `/${locale}${path}`;
}

export function alternatesFor(locale: Locale, path: Path) {
  return {
    canonical: localizedPath(locale, path),
    languages: {
      tr: localizedPath('tr', path),
      en: localizedPath('en', path),
      'x-default': localizedPath(routing.defaultLocale, path),
    },
  };
}
```

- [ ] **Step 5: Write the sitemap and robots**

`src/app/sitemap.ts`:

```ts
import type { MetadataRoute } from 'next';
import { site } from '@/config/site';
import { localizedPath } from '@/i18n/alternates';
import { routing } from '@/i18n/routing';

const abs = (path: string) => `${site.siteUrl}${path === '/' ? '' : path}`;

export default function sitemap(): MetadataRoute.Sitemap {
  return (['', '/privacy'] as const).flatMap((path) =>
    routing.locales.map((locale) => ({
      url: abs(localizedPath(locale, path)),
      alternates: {
        languages: Object.fromEntries(
          routing.locales.map((l) => [l, abs(localizedPath(l, path))]),
        ),
      },
    })),
  );
}
```
